## 🚀 How to Run Locally

Because this project is built using standard, lightweight **HTML5, CSS3, and modern Vanilla JavaScript**, you do not need heavy node packages or build tools!

### Option 1: Double Click
Simply double-click `index.html` in your file manager to open it directly in any browser.

### Option 2: Using Python's built-in server
```bash
python3 -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Deploying to GitHub Pages (Free, 1-Click)

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Add Laxmi Jewellers premium landing page"
   git push origin main
   ```
2. On GitHub, go to your repository **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Within 1–2 minutes, your website will be live at `https://<your-username>.github.io/<repo-name>/`.

---

## ▲ Deploying to Vercel (Free & Instant)

1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **Add New** > **Project**.
3. Select your repository.
4. Leave Framework as **Other** (since it is a static HTML/CSS/JS site with zero build configuration needed).
5. Click **Deploy**. Your site will be live instantly with global CDN and free SSL!
